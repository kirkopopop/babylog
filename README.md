# Baby log

Shared baby log for logging sleep, bottles, meals, nappies, vitamin D, medicine, growth and milestones, with trends and targets.

- **Front end:** Vite + plain JavaScript, installable as a home-screen app (PWA). Deployed on Vercel.
- **Data:** the hjem Supabase project (`babies`, `baby_events`), access limited to members of the household via RLS. Sign-in uses hjem accounts.
- **Sync:** realtime updates between phones; entries are saved locally first and synced when online.
- **Import:** Settings → Import from MyBaby takes the MyBaby events CSV; re-importing skips entries already there.

```
npm install
npm run dev     # local
npm run build   # dist/
```

Growth percentiles use WHO Child Growth Standards LMS tables (0–24 months), in `src/who.json` (generated by `scripts/who.py`).
